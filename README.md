## Introduction

In this session, we will learn how to analyse ATAC-seq. The analysis pipeline can be divided into seven parts:

1. Read processing
2. Alignment
3. Coverage
4. Peak calling
5. Differential analysis
6. Functional analysis
7. Multiomics integration

We will use ATAC-seq data from a study where the authors aimed to characterize the chromatin accessibility dynamics of plant regeneration (Wu et al. 2022).

Briefly, Arabidopsis explants were treated with callus induction medium (CIM) for seven days and then transferred to shoot induction medium (SIM) for eight days. CIM induces proliferation of pluripotent cells, while SIM promotes their differentiation into shoots. Using ATAC-seq, we can investigate the changes in chromatin accessibility associated with these biological processes.

Samples were collected at seven time points in the original experiment. However, due to time constraints, today we will focus on three time points: **CIM7, SIM6 and SIM8**. To speed up the analysis, Parts 1–4 will use a small subset of the reads mapping to the first chromosome (Chr1:1–1,000,000), while Parts 5–7 will use precomputed results from the complete dataset.

## Part 1. Read preprocessing

We will start by checking the quality of the sequencing reads. Reads are stored in `/data/classes/seg_epig2026/data/atac_session/00_raw_data`. For ATAC-seq, it is particularly important to check for adapter contamination at the 3′ ends of the reads. We will use **FastQC** to assess the quality of the raw FASTQ files.

```
bash scripts/01_qc.sh
```

FastQC generates an HTML report and a compressed data file for each FASTQ file. For convenience, we have combined the FastQC results into a single report using **MultiQC**.

Transfer the FastQC and multiQC reports to your computer. Open `multiqc_raw.html` and inspect the **Adapter Content** section. You can also explore the individual FastQC reports.

**1.1. Do any samples contain the Nextera Transposase Adapter?**

If adapter contamination is present, we should remove the adapter sequences before continuing. We will use **cutadapt** for adapter trimming and then run FastQC and MultiQC again on the trimmed reads.

```
bash scripts/02_trim.sh
```

Transfer the new FastQC and multiQC reports to your computer. Inspect the new `multiqc_trimmed.html` report and the FastQC reports.

**1.2. Are the trimmed reads free of adapter contamination?**

## Part 2. Alignment

Now that our reads have been processed, they are ready to be aligned to a reference genome. Most aligners require an index generated from a FASTA file containing the reference sequence.

Since our samples are from Arabidopsis thaliana, we will use the **TAIR10** assembly as the reference. The reference genome is already available on the server, so there is no need to download it.

For alignment, we will use **BWA**. We will then sort the alignments by genomic coordinates using `samtools sort` and mark duplicate alignments using `picard MarkDuplicates`.

```
bash scripts/03_align.sh
```

After alignment, we need to remove alignments that are not suitable for downstream ATAC-seq analysis. These include multimapping reads, duplicate reads, improperly paired reads, and reads mapping to blacklisted regions such as organellar chromosomes. We will perform these filtering steps using samtools view.

Finally, we will collect alignment statistics using samtools stats.

```
bash scripts/04_filter.sh
```

We will use the resulting statistics to calculate several library QC metrics:

* Percentage of duplicated alignments
* Percentage of alignments in blacklisted regions
* Percentage of reads retained after filtering
* Fragment size distribution

We will plot these metrics using R:

```
Rscript scripts/05_library_qc.R
```

Inspect the library QC plots.

**2.1. Do any samples display concerning amounts of discarded reads?**
**2.2. Does the fragment size distribution show the expected pattern?**

## Part 3. Coverage

Now that we have aligned our reads and retained high-confidence alignments, we need to assess the quality of the ATAC-seq signal.

One important aspect of ATAC-seq data quality is the **signal-to-background ratio**. We will first visualize the coverage of the alignments in a genome browser. We will perform the Tn5 shift and obtain coverage tracks using various bedtools commands and normalize them to **counts per million mapped reads (CPM).**

```
bash scripts/06_coverage.sh
```

Transfer the bigwig files of `results/06_coverage` to your computer and load the .cpm.bw files into IGV.

Select all the tracks, right-click, and select **Group Autoscale**. Navigate through the genome to explore the ATAC-seq signal.

**3.1. Does the experiment show a good signal-to-background ratio?**

We can also quantify enrichment around transcription start sites (TSSs) across the genome using **TSS enrichment scores.**

```
Rscript scripts/07_tss_enrichment.R
```

Transfer the figures to your computer and inspect them.

**3.2. Based on the TSS enrichment and gene-body plots, would you consider these samples to be good quality?**

## Part 4. Peak calling

After assessing the ATAC-seq signal, we need to identify genomic regions where accessibility is significantly enriched above the background. These regions are identified through peak calling.

We will use **MACS3** to identify peaks of chromatin accessibility.

```
bash scripts/08_peak_calling.sh
```

The peak calls are available in `results/08_peak_calling`. Transfer the narrowPeak files to your computer and load them into your IGV session.

**4.1. Do the peak intervals correspond well to the ATAC-seq signal?**

You may notice that some peaks are present in only one biological replicate, while others are shared between replicates. Peaks that are not reproducible between replicates are generally less confident.

We therefore generated a consensus peak set for each condition by requiring peaks to be reproducible between replicates and supported by pooled peak calling. We then merged the consensus peak sets from the different conditions to generate a union peak set, which will be used for downstream analyses.

We will quantify accessibility at these peaks for all samples using a DiffBind-style approach. For each peak, we identify its summit—the base pair with the maximum signal—and count the signal in a 200-bp window centred on the summit.

```
Rscript scripts/09_counts.R
```

Finally, we will annotate the peaks according to their genomic location and nearest gene using ChIPseeker:

```
Rscript scripts/10_annotation.R
```

Inspect the pie chart we generated showing the percentage of peaks assigned to different genomic features.

**4.2. What genomic regions are ATAC-seq peaks most enriched in this dataset?**

## Part 5. Differential accessibility

Once we have defined a common set of accessible regions and quantified their accessibility across samples, we can compare conditions to identify regions whose accessibility changes.

Differential accessibility can be analysed using methods such as **DESeq2** or **edgeR**. In this session, we will use **DESeq2**.

```
Rscript scripts/11_differential.R
```

Before performing differential analysis, it is useful to examine the similarity between samples. This allows us to assess whether biological replicates behave consistently and whether there are any unexpected differences between samples.

We applied a variance-stabilizing transformation to the count data and used the transformed values for **Principal Component Analysis (PCA)**. The transformation is used here to make the data suitable for visualization and clustering; it is not used to perform the differential analysis itself.

**5.1. Do biological replicates cluster together in the PCA?**

In this session, we will compare SIM6 and CIM7 to identify differentially accessible regions (DARs) associated with the transition from callus induction to shoot induction. As with RNA-seq, DESeq2 models the count data while accounting for differences in sequencing depth between samples and estimates the significance of the difference between conditions.

We represented the magnitude of differential accessibility (log2 fold change between conditions) and the significance (adjusted p-value) using a volcano plot. Inspect the volcano plot and the barplot showing DARs according to genomic feature.

**5.2. How many DARs are detected between SIM6 and CIM7?**

**5.3. Is there a trend towards increased or decreased accessibility in any particular genomic feature?**

Download the full bigwig files from `/data/classes/seg_epig2026/data/atac_session/00_full_data/`. Load them into IGV and look at the accessibility dynamics of the following loci: AT5G10510 (PLT3), AT3G48100 (ARR5).

**5.4. How does accessibility change from CIM to SIM in PLT3? and ARR5?**

## Part 6. Functional characterization

Once we have identified DARs between two conditions, the next question is: **what might these changes mean biologically?**

There are several ways to investigate this. In this session, we will focus on two approaches:

1. **Gene Ontology (GO) enrichment** — identifies biological processes that are statistically overrepresented among the genes associated with the DARs.
2. **TF motif enrichment** — identifies transcription factor binding motifs that are overrepresented in the DARs, providing clues about transcription factors that may be involved in the observed changes.

GO enrichment can be performed using **clusterProfiler**.

```
Rscript scripts/12_go.R
```

Inspect the dotplot representing significantly enriched biological processes in up- and down- DARs.

**6.1. What biological processes are enriched in the up- and down-DARs?**

We will perform TF motif enrichment using SEA (Simple Enrichment Analysis) with the JASPAR plants collection of motifs.
```
python3 scripts/13_motifs.py
```
Transfer the SEA output folders in results/13_motifs to your computer and open the sea.html files corresponding to the up- and down-DARs.

**6.2. Is any TF family particularly enriched in the up- or down-DARs?**

## Part 7. Multiomics integration

ATAC-seq is often combined with other genomic approaches, such as RNA-seq. Integrating these datasets allows us to investigate whether changes in chromatin accessibility are associated with changes in gene expression.

In this session, we will integrate changes in ATAC-seq accessibility with changes in RNA-seq expression. The RNA-seq was performed on the same time points as the ATAC-seq. Therefore, we can study how accessibility and expression are connected during the CIM7 to SIM6 transition.

```
Rscript scripts/14_integration.R
```

Inspect the scatter plot showing RNA-seq and ATAC-seq fold changes.
